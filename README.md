# MSCS532 Assignment 2: Divide-and-Conquer Sorting

Python implementations of **merge sort** and **quick sort**, two classic
divide-and-conquer sorting algorithms from Chapter 7 of Cormen,
Leiserson, Rivest & Stein, *Introduction to Algorithms* (4th ed., 2022).

The repository will also contain a benchmark that compares the two
algorithms on sorted, reverse-sorted, and random inputs, measuring
execution time and peak memory.
